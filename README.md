## Sistema de Contratación de Personal

# Descripción

Programa desarrollado en lenguaje C que permite evaluar candidatos para un proceso de contratación. El sistema analiza la experiencia laboral y las habilidades técnicas del aspirante para determinar si cumple con los requisitos establecidos por la empresa.

## ¿Qué problema resuelve?

Este programa ayuda a automatizar la evaluación inicial de candidatos, reduciendo errores en la toma de decisiones y agilizando el proceso de selección de personal mediante la aplicación de criterios previamente definidos.

## Funcionalidades

• Solicita los años de experiencia del candidato.
 • Solicita si el candidato posee buenas habilidades técnicas.
 • Evalúa las condiciones de contratación establecidas por la empresa.
 • Determina automáticamente si el candidato es contratado o no cumple con los requisitos.
 • Muestra el resultado de la evaluación en pantalla.

## Tecnologías utilizadas

• Lenguaje C.
 • Programación orientada a consola.
 • Proyecto realizado para la materia de Programación - UTP.

## Instalación y ejecución

Clonar o descargar el repositorio.

Abrir el archivo fuente en Visual Studio Code o cualquier compilador compatible con C.

Compilar el programa mediante el siguiente comando:

gcc contratacion.c -o contratacion

Ejecutar el programa:

./contratacion

Ingresar los años de experiencia del candidato.

Indicar si posee buenas habilidades técnicas.

Visualizar el resultado de la evaluación mostrado por el sistema.

## Reglas de evaluación

• Si tiene 5 años o más de experiencia → Contratado.
 • Si tiene 3 años o más de experiencia y posee buenas habilidades técnicas → Contratado.
 • Si no cumple las condiciones anteriores → No cumple requisitos.
