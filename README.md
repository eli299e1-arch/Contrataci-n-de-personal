# Contratacion-de-personal
Determinar si una empresa debe contratar a un candidato basandose según su experiencia


### Reglas:
- Si tiene 5 anos o mas de experiencia -> Contratado
- Si tiene 3 anos o mas Y tiene buenas habilidades tecnicas (1) -> Contratado
- Si no cumple lo anterior -> No cumple requisitos

Lenguaje: C
